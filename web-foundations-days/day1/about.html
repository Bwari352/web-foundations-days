About QuickNotes

QuickNotes is a simple web application that allows you to capture your ideas and notes quickly before they disappear. It is built using HTML and is designed to be user-friendly and efficient.

With QuickNotes, you can easily add new notes, view your existing notes and keep track of your ideas in one convenient place.

How to use QuickNotes

  1. Type your note in the input field.
  2. Click the "Add Note" button to save your note.
  3. Your notes will be displayed in the list below.

Features

  • Add new notes quickly.
  • View your existing notes.
  • Simple and intuitive interface.

Keyboard Shortcuts

Shortcut Action
Ctrl + N Add a new note
