# Day 8 Reflection

The most difficult concept I learned during this course was designing systems that can handle high traffic while maintaining data consistency. At first, it was challenging to understand how multiple users could access the same resource at the same time without causing errors. I overcame this by breaking the concepts into smaller parts and studying how load balancers, caching, database transactions and constraints work together. Practicing system design through the QuickNotes project also helped me understand how different components communicate and why architecture decisions matter.

Based on the feedback and lessons from my capstone, I would improve the architecture documentation and make the system design diagrams clearer. I would also improve the error-handling process and explain more clearly how the application behaves when an API request fails or when the server is unavailable. This would make the project easier to understand, test and maintain.

Next, I want to learn more about cloud computing, deployment and practical database optimization. I would like to deploy a web application to a cloud platform, configure monitoring and learn how to scale it when the number of users increases. I also want to improve my knowledge of automated testing, security and CI/CD pipelines. These skills will help me build reliable applications and prepare me for real-world software development work.
